MATCH-3 BOSS FIGHT — ROADMAP ФИЧЕЙ
====================================
Цель: приблизиться к уровню Royal Match / Royal Kingdom

Текущее состояние: MVP готов — борда 8x7, 4 типа тайлов, 3 бустера (Row/Col/Ultimate),
бомбы босса, 4 скилла игрока, босс с 4 абилками, каскады, flying tiles, хинты.


═══════════════════════════════════════
  1. ВИЗУАЛЬНЫЙ JUICE
═══════════════════════════════════════

1.1  Combo counter ("x2!", "x3!", "Awesome!")
     → При каскадных матчах — растущий счётчик по центру борды
     → При x3+ текст: "Great!", "Amazing!", "Incredible!"
     → Scale bounce + fade анимация
     Сложность: НИЗКАЯ | Импакт: ВЫСОКИЙ

1.2  Bounce при приземлении тайлов
     → После collapse тайлы сжимаются по Y и пружинят (squash & stretch)
     → scaleY 0.8→1.0 с Back.easeOut
     Сложность: НИЗКАЯ | Импакт: ВЫСОКИЙ

1.3  Screen shake при больших комбо и бустерах
     → Camera shake при активации BoosterRow/Col/Ultimate
     → Усиленный shake при каскаде x3+
     Сложность: НИЗКАЯ | Импакт: СРЕДНИЙ

1.4  Glow/свечение на special тайлах
     → BoosterRow/Col/Ultimate постоянно слегка пульсируют
     → Выделяются на борде, притягивают внимание
     Сложность: НИЗКАЯ | Импакт: СРЕДНИЙ

1.5  Линия разрушения при BoosterRow/Col
     → Светящийся луч пролетает по ряду/колонке перед очисткой
     → Как лазер в Royal Match
     Сложность: СРЕДНЯЯ | Импакт: ВЫСОКИЙ


═══════════════════════════════════════
  2. ГЕЙМПЛЕЙНЫЕ МЕХАНИКИ
═══════════════════════════════════════

2.1  Комбо-множитель урона при каскадах
     → 1й каскад: x1, 2й: x1.5, 3й: x2, 4й+: x2.5
     → Мотивирует строить длинные цепочки
     Сложность: НИЗКАЯ | Импакт: ВЫСОКИЙ

2.2  Комбинации бустеров (booster + booster swap)
     → Свап двух спецтайлов = мега-эффект:
       • Row + Col = крест (как Ultimate)
       • Row/Col + Ultimate = все ряды или все колонки
       • Ultimate + Ultimate = очистка всей борды
     → Главный стратегический элемент (как в Royal Kingdom)
     Сложность: СРЕДНЯЯ | Импакт: ОЧЕНЬ ВЫСОКИЙ

2.3  L/T-shape матч → новый спецтайл (Bomb 3x3)
     → L-shape или T-shape из 5 тайлов → Bomb (радиус 3x3)
     → Как Dynamite в Royal Kingdom
     Сложность: СРЕДНЯЯ | Импакт: ВЫСОКИЙ

2.4  Фазы босса
     → 50% HP → 2-я фаза: новые абилки, ускоренный паттерн
     → 25% HP → 3-я фаза: enrage
     → Уже есть damaged sprite при 50%
     Сложность: СРЕДНЯЯ | Импакт: СРЕДНИЙ

3.1  Score / очки с множителем

3.2  Превью хода (подсветка что очистится)

     Сложность: СРЕДНЯЯ | Импакт: СРЕДНИЙ

3.3  Анимированная победа / поражение

     → Сейчас — простой overlay с текстом
     Сложность: НИЗКАЯ | Импакт: СРЕДНИЙ
