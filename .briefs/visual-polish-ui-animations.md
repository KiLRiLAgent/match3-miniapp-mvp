# Feature Brief: Визуальный полиш и доработки UI/анимаций

## Intent
Улучшить визуальное качество и полировку Match-3 игры: убрать визуальные артефакты (два арта девочки одновременно при катсцене, дёрганье damage art при каскадных матчах), усилить обратную связь (вспышки баров, эффекты разреза, trailing delta HP), улучшить читаемость UI (иконки перед барами), доработать туториал и увеличить сочность анимаций.

## Audience
Все игроки Telegram Mini App

## Success Criteria

### 1. Фейд арта девочки при катсцене босса
При полноэкранной атаке босса — арт девочки (bossImage + bossImageGlow + bossGlowBrightness) за полем матч3 уходит в фейд (alpha → 0) ДО показа полноэкранного арта катсцены. Не должно быть двух девочек одновременно на экране. После окончания катсцены — арт девочки возвращается через фейд.

### 2. Damage art девочки — сохранение до конца хода
Сейчас при каскадных матчах арт дёргается туда-сюда (переключение idle→damage→idle на каждый матч). Нужно:
- При первом попадании урона — переключить на damage art
- Оставить damage art до конца ВСЕГО хода (пока все матчи/каскады не завершатся)
- Только после этого переключить обратно в idle через фейд
- Засвет (flash/brightness pulse) оставить — он должен срабатывать на КАЖДЫЙ хит урона

### 3. Свечение match-4/5 ярче
Сделать свечение (tileGlows) для match-4 и match-5 фишек заметно ярче текущего. Увеличить alpha, размер, или интенсивность glow текстур (tile_glow_gold, tile_glow_red).

### 4. Размер фишек 115%
Изменить масштаб фишек с текущих 110% (CELL_SIZE * 1.1) на 115% (CELL_SIZE * 1.15).

### 5. Доработка туториала
На основе макета (скриншот):
- Предустановленная комбинация из 3 мечей по центру поля (не из 5 как сейчас)
- Затемнение всего поля кроме UI девочки и игрока — остаётся высветленным только место для матча
- На этих фишках проигрывается туториальная анимация матча
- Показан бабл с текстом "Составь комбинацию из МЕЧЕЙ, чтобы атаковать!" — крупнее и по центру
- Туториальный палец появляется из фейда на верхней фишке мечей, затем сдвигается вниз чтобы подвинуть фишку и уходит в фейд — палец крупнее чем сейчас
- Всё управление заблокировано кроме одного этого свайпа
- Как только игрок делает матч — тутор заканчивается, поле быстро высветляется, бабл и палец пропадают
- Фраза девушки в начале уровня переносится на после тутора (не "Этого нету" — просто перенести)

### 6. Улучшение анимации полёта фишек
Перспективное масштабирование:
- Стартовый размер фишки в начале полёта — чуть БОЛЬШЕ чем на поле (фишка вылетает над полем, становится ближе к игроку)
- Увеличить шлейф (trail) пропорционально стартовому размеру
- По мере полёта к цели — плавное уменьшение размера
- Финальный размер при влёте в цель — чуть МЕНЬШЕ чем на поле (цель находится немного за полем, фишка удаляется)
- Итого: фишка вылетает крупной → летит с уменьшением → влетает в цель чуть меньшей

### 7. Анимация изменения баров (игрок)
На мгновение подсвечивать (увеличивать яркость) цветную часть полоски HP/MP бара при изменении значения. Например: игрок получил ману → MP бар подсветился. Игрок получил урон → HP бар подсветился.

### 8. Доработка UI игрока
- HP бар игрока всегда зелёный (в цвет фишки хила), убрать динамическую смену цвета green→orange→red
- Перед HP баром игрока поставить иконку фишки хила (tile_heal)
- Перед MP баром игрока поставить иконку фишки маны (tile_mana)

### 9. Эффект разреза в анимации атаки
Используя графику splash_1.png и splash_2.png из корня проекта:
- Одинарный разрез (splash_1.png) — на обычные атаки по девочке (матч мечей/звёзд) и атаки по игроку
- Двойной разрез (splash_2.png) — на сильные атаки: ульта девочки (powerStrike), способности игрока (skills)
- Эффект появляется поверх цели в момент нанесения урона

### 10. HP бар босса — trailing delta
Анимация уменьшения HP бара босса по принципу "trailing delta":

**0. Начальный стейт**: Красный HP бар + серый пустой участок

**1. Влетел урон**:
- Вся красная полоска на мгновение подсвечивается (повышается яркость)
- HP бар мгновенно уменьшается на нужное деление
- На участке между старым и новым положением HP бара появляется белая "дельта"

**2. Каскадные матчи**:
- Если влетает ещё урон во время секвенции матчей — дельта увеличивается (вместе с уменьшением HP бара), показывая сколько всего урона было нанесено за ход

**3. Конец секвенции**:
- Когда все матчи завершились — дельта плавно сокращается справа налево и полностью исчезает

## Exclusions
- Не менять механику боя/урона (формулы, значения)
- Не менять логику матч-3 (Board.ts) — только визуальная часть
- Не трогать IntroScene (кинематик начала уровня)

## Project Context

### Stack
- Phaser 3.88.2 + TypeScript 5.9.3 + Vite 7.2.4
- Telegram Mini App
- GitHub Pages deployment (docs/)

### Key Architecture
- **Boss art**: 3-layer system (bossImageGlow depth -0.1, bossGlowBrightness depth -0.05 ADD blend, bossImage depth 0)
- **Damage flash**: мгновенная смена на damage art + shake 300ms + crossfade back, `bossFlashActive` flag
- **Cutscene**: `withCutscene()` — overlay alpha 0.6 + fullscreen boss art depths 500-502, НЕ скрывает основной арт
- **Flying tiles**: FlyingTile.ts, 32px base, Bezier trajectory, `flyingTileScaleReduction = 0.6`, trail 6px dots
- **Tile scale**: `CELL_SIZE * 1.1` в `spawnTileSprite`
- **Hint glows**: alpha 0.15→0.6, gold/red radial gradients, depth 0.99, pulse 800ms
- **Meter.ts**: Graphics-based bars, rounded rectangles, dynamic HP color (green→orange→red)
- **Tutorial**: preset board + hand_arrow + SpeechBubble, 5-sword match at (4,2)→(4,3)
- **Assets**: splash_1.png, splash_2.png в корне — не подключены

### Key Files
- `src/scenes/GameScene.ts` (~2600 lines) — main scene, cutscene, damage, tutorial
- `src/ui/FlyingTile.ts` — flying tile animation
- `src/ui/Meter.ts` — HP/MP bars
- `src/game/animations.ts` — animation config
- `src/game/config.ts` — game constants, UI layout
- `src/game/assets.ts` — asset key registry
- `src/scenes/BootScene.ts` — texture generation, asset loading
