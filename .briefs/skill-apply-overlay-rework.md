# Feature Brief: Skill Apply Overlay Rework

## Intent
Полностью переделать UI подтверждения скилла (SkillApplyOverlay) с текущей большой тёмной панели на компактную горизонтальную карточку поверх игрового поля, как в макете из Miro. Текущий UI занимает 70%+ экрана с огромным пустым пространством — должна быть компактная карточка с информацией о скилле, превью эффекта на HP барах и подсветкой целевых элементов.

## Audience
Все игроки v1 — overlay появляется при нажатии на разблокированный скилл в бою.

## Success Criteria
1. **Компактная карточка** — информация о скилле отображается как небольшая горизонтальная карточка над игровым полем (НЕ как модальная панель на весь экран)
2. **Layout карточки** — слева иконка скилла крупно + звёзды под ней, справа: название (красный/жёлтый bold), стоимость (💧 маны), перезарядка (⏳ ходов), описание эффекта (⚔ урон / +HP)
3. **Зелёная кнопка "Применить!"** — по центру нижней части экрана, крупная, отдельно от карточки
4. **Превью на HP барах** — на HP баре босса/игрока визуально показано сколько отнимется/прибавится (белая/зелёная секция предварительного эффекта)
5. **Подсветка целевых элементов UI** — высветлены элементы на которые действует скилл (HP бар босса для урона, HP бар игрока для хила) + сама иконка скилла внизу
6. **Закрытие — тап мимо карточки** — без кнопки X, нажатие вне карточки закрывает оверлей
7. **Игровое поле видно** — лёгкое затемнение фона, но поле и HUD просвечивают (не глухой чёрный overlay)

## Exclusions
- Не менять логику применения скиллов (PerkManager, damage calculation)
- Не менять сами SkillButton-ы (уже обновлены в текущей сессии)
- Не трогать PerkCard (выбор перков при levelup) — это другой UI

## Additional Context
- Закрытие оверлея: тап вне карточки (без кнопки X)
- Из макета: у Молотка (Взрыв камня) вместо кнопки "Применить!" — подсвеченная клетка поля (т.к. скилл таргетит клетку). Это можно отложить на потом, для текущей задачи все скиллы используют кнопку "Применить!"

## Project Context
- **Stack**: Phaser 3 + TypeScript, Vite bundler
- **Текущий файл**: `src/ui/SkillApplyOverlay.ts` (~310 строк) — полная перезапись
- **Зависимости**: вызывается из `GameScene.ts`, получает SkillDef + callbacks
- **HP бары**: `src/ui/Meter.ts` / `src/ui/LayeredMeter.ts` — нужен метод для показа превью (delta preview)
- **Depth**: текущий overlay на depth 1500 (между game-end UI и Toast)
- **Скилл-кнопки**: `src/ui/SkillButton.ts` — уже обновлены (badge маны на кнопке)
- **Config**: `src/game/config.ts` — SKILL_CONFIG, UI_LAYOUT
