# Feature Brief: CRIT система, перки, визуальный полиш v3

## Intent
Крупное обновление геймплея: заменить бустеры на CRIT-систему с множителями, добавить систему перков (апгрейды скилов при снятии слоёв HP босса), визуальные доработки (прямые края баров, виньетка при низком HP, увеличение летящих фишек).

## Audience
Все игроки Telegram Mini App

## Success Criteria

### 1. Match 4/5 → CRIT система (замена бустеров)
Полностью убрать бустеры (BoosterRow, BoosterCol, Ultimate):
- Match 3: обычный матч, как сейчас
- Match 4: все 4 фишки уничтожаются (НЕ создаётся бустер), выскакивает надпись "CRIT! x2" над фишками. Эффект от фишек умножается на 2 (4 фишки × 2 = 8 фишек эффекта)
- Match 5+: все фишки уничтожаются, надпись "MEGA CRIT! x3". Эффект × 3 (5 фишек × 3 = 15 фишек эффекта)
- Убрать генерацию спецтайлов в Board.ts (BoosterRow/Col/Ultimate)
- Убрать текстуры и логику активации бустеров
- Надпись CRIT: крупный текст с анимацией (scale bounce + fade), цвет золотой/красный

### 2. Летящие фишки ещё больше
Увеличить startScale и endScale в animations.ts FLYING_TILE:
- startScale: текущее 1.45 → увеличить до ~1.6
- endScale: текущее 0.95 → увеличить до ~1.05
- Trail пропорционально

### 3. HP/Mana бары игрока — прямые правые края
Meter.ts: применить per-corner radius как в LayeredMeter:
- drawFill: `fillRoundedRect(x, 0, w, h, {tl: r, tr: 0, bl: r, br: 0})` при partial
- drawDelta: аналогично
- drawHighlight: аналогично
- flash: аналогично
- При полной ширине — все углы скруглены (radius)

### 4. Счётчик слоёв HP — внутрь бара
LayeredMeter.ts: переместить counterText ("x6") из-за правого края бара — внутрь бара.
- Позиция: правая часть бара, с отступом от правого края
- Текст поверх fill (depth выше fill но внутри контейнера)
- Достаточно крупный чтобы читался

### 5. HP множители по слоям в настройки + фикс скролла
SettingsPanel.ts:
- Добавить настройку "HP per layer" (slider или input, default 100)
- Добавить настройку "Layer count" (default 10)
- Починить скролл в панели настроек (если не скроллится)

### 6. Система перков
**Триггер**: Когда снимается полоска HP босса (переход между слоями) →
1. Всё замирает (pause gameplay)
2. Надпись "Новый уровень!" по центру экрана
3. Появляются 3 карточки перков (случайные из доступных)

**Карточка перка**:
- Название (сверху, золотой текст на тёмном фоне)
- Иконка скила (в центре, круглая)
- Стоимость маны (слева от иконки)
- Уровень перка: 5 звёзд внизу (золотые = текущий уровень, мигающая = следующий)
- Описание (внизу карточки, меняется по уровню)
- Золотая рамка вокруг карточки

**Перки = апгрейды 4 скилов**:
- PowerStrike: каждый уровень +20% урона или -5 маны
- Stun: каждый уровень +1 ход стана или -10 маны
- Heal: каждый уровень +10 HP хила или -5 маны
- Hammer: каждый уровень -5 маны или -1 кулдаун

**Механика**:
- 3 случайных перка из 4 доступных (не показывать макс уровень 5)
- Игрок кликает на карточку → получает/прокачивает перк
- Звёзды на кнопке скила обновляются
- Игра продолжается
- Всего 5 уровней, на 5м перк больше не предлагается

### 7. Красная виньетка при низком HP
Когда HP игрока < 30% от максимума:
- Показать полупрозрачную красную рамку по краям экрана (виньетка)
- Лёгкая пульсация (alpha 0.2 → 0.4 → 0.2)
- Исчезает когда HP восстанавливается > 30%
- Depth: выше поля, ниже HUD (примерно 5-6)

## Exclusions
- IntroScene не трогать
- Механику урона/хила не менять (только множители CRIT)
- Существующие скилы не удалять, только добавить уровни через перки

## Project Context

### Stack
- Phaser 3.88.2 + TypeScript 5.9.3 + Vite 7.2.4
- Telegram Mini App, GitHub Pages deploy

### Key Architecture
- **Board.ts**: матч-3 логика, findMatches(), computeClearOutcome(), бустеры создаются здесь
- **GameScene.ts** (~2800 lines): основная сцена, resolveBoard(), applyMatchResults(), скилы
- **Meter.ts**: HP/MP бары игрока, fillRoundedRect, trailing delta
- **LayeredMeter.ts**: многослойный HP босса, per-corner radius уже реализован
- **SkillButton.ts**: кнопки скилов с иконкой маны
- **FlyingTile.ts**: летящие фишки с perspective scaling
- **animations.ts**: FLYING_TILE config (startScale, endScale)
- **config.ts**: BOSS_LAYER_COUNT, BOSS_HP_PER_LAYER, TILE_DISPLAY_SCALE
- **SettingsPanel.ts**: панель настроек с параметрами игры

### Key Files
- `src/match3/Board.ts` — матч-3 логика, тут создаются бустеры
- `src/match3/types.ts` — TileKind enum (BoosterRow, BoosterCol, Ultimate)
- `src/scenes/GameScene.ts` — основная сцена
- `src/ui/Meter.ts`, `src/ui/LayeredMeter.ts` — бары
- `src/ui/SkillButton.ts` — кнопки скилов
- `src/ui/FlyingTile.ts` — летящие фишки
- `src/game/config.ts` — константы
- `src/game/animations.ts` — анимации
- `src/ui/SettingsPanel.ts` — настройки
