# Feature Brief: Stat Point Allocation + Level Reset

## Intent
Заменить автоматический прирост статов при level-up на систему ручного распределения очков. Добавить кнопку полного сброса уровня для тестирования/рестарта.

## Audience
Все игроки v2.

## Success Criteria

### 1. Stat point allocation при level-up
- Каждый уровень даёт **1 очко** (stat point)
- Очко можно потратить на ОДНО из 4 улучшений:
  - **+5 HP** максимального здоровья
  - **+4 MP** максимальной маны  
  - **+2 физической атаки**
  - **+2 магической атаки**
- UI показывает 4 строки со статами, кнопка **[+]** для повышения, кнопка **[-]** для снижения (пока не сохранено)
- Кнопка **«Сброс»** сбрасывает текущее незакреплённое распределение (возвращает все нераспределённые поинты)
- Кнопка **«Сохранить»** закрепляет выбор **навсегда** — после нажатия нельзя перераспределить эти очки
- Если есть нераспределённые очки (pending points) — показывать счётчик "Доступно очков: N"
- [-] работает ТОЛЬКО для ещё не сохранённых очков (уже закреплённые нельзя снять)

### 2. Изменение текущей системы прогрессии
- **Убрать автоматический прирост** статов при level-up в ProgressionSystem (текущий: +20 hp / +10 mp / +1 phys / +1 mag per level)
- Вместо авто-прироста: каждый level-up добавляет 1 pending stat point
- Базовые статы игрока (level 1) остаются как есть: 200 HP, 100 MP, 10 phys, 10 mag
- Формула: `effectiveStat = baseStat + allocatedPoints[stat] * statPerPoint[stat]`

### 3. UI в PlayerStatsScene
- В секции "Базовые статы" показывать:
  - Текущие статы с учётом распределённых очков
  - Если есть pending points: кнопки [+] и [-] рядом с каждым статом
  - Счётчик "Доступно очков: N" (жёлтый, заметный)
  - Кнопка «Сброс» (сбрасывает pending, не сохранённые)
  - Кнопка «Сохранить» (закрепляет выбор навсегда)
- Если все очки распределены и сохранены — кнопки [+]/[-] скрыты, просто отображаются статы

### 4. Кнопка «Сбросить уровень» (dev/debug feature)
- В PlayerStatsScene, внизу: кнопка «Сбросить прогрессию»
- При нажатии: confirmation modal (как SellConfirmModal) → "Сбросить уровень до 1? Все статы и очки будут обнулены."
- При подтверждении:
  - `player.level = 1`
  - `player.xp = 0`
  - Все allocated stat points обнуляются
  - Все pending stat points обнуляются
  - Toast: "Прогрессия сброшена"
  - `scene.refresh()`

### 5. SaveData changes
- Новые поля в `PlayerSave`:
  - `allocatedStats: { hp: number, mp: number, physAttack: number, magAttack: number }` — сохранённые распределения
  - `pendingStatPoints: number` — нераспределённые очки (= уровень - 1 - totalAllocated)
- Migration: при загрузке старого save, вычислить сколько очков игрок "должен был" получить (level - 1), и установить их как pending

## Exclusions
- НЕ добавлять крит как allocatable stat (только HP/MP/phys/mag)
- НЕ менять v1 GameScene напрямую (только через существующие v2 feature gates)
- НЕ менять ArenaSystem/PerkSystem — распределение статов отдельно от перков и бафов
- НЕ позволять перераспределение уже СОХРАНЁННЫХ очков (только pending можно двигать)
