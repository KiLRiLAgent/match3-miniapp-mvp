# Feature Brief: Item Info Display in PlayerStatsScene

## Intent
Игрок должен понимать, что даёт каждый предмет, не заходя в код или магазин. Сейчас в PlayerStatsScene экипировка и рюкзак показывают только имя — статы и лорные описания скрыты, хотя уже существуют в `ItemDef` (`src/v2/content/types.ts`).

## Audience
Игроки v2 — любой, кто открывает PlayerStatsScene чтобы собрать билд или разобраться в своих предметах.

## Success Criteria
1. Рядом с именем каждого предмета (и в слотах экипировки, и в рюкзаке PlayerStatsScene) сразу видна краткая сводка статов в формате `+10 физ, +5 HP` — такая же, как уже существует в ShopScene.
2. У каждой строки предмета есть заметная иконка ℹ️ (или восклицательный знак) справа, с **отдельной hit-area**, чтобы тап по иконке не срабатывал как equip/unequip.
3. Тап по иконке открывает модальный попап с полной карточкой предмета:
   - Имя (в цвете редкости)
   - Слот (Оружие / Броня / Аксессуар)
   - Редкость (текст + цветовая индикация)
   - Все статы списком
   - Лорное описание из `ItemDef.description`
4. Попап, открытый для предмета из **рюкзака**, дополнительно показывает **сравнение** с текущим экипированным предметом в том же слоте: `+3 физ / -1 крит` с цветовой подсветкой (зелёный плюс / красный минус). Если слот пустой — просто полная карточка без сравнения.
5. Попап, открытый для уже **экипированного** предмета, показывает полную карточку без сравнения.
6. Закрытие попапа: тап вне него (по затемнённому бэкдропу) и/или кнопка × / «Закрыть».
7. Существующая логика equip/unequip по тапу на строке **не сломана**, drag-scroll продолжает работать как раньше (иконка и попап не перехватывают/не ломают gesture detection).

## Exclusions
- **НЕ трогать** ShopScene, ArenaRewardScene, PostCombatScene, CharacterGalleryScene — только PlayerStatsScene.
- **НЕ добавлять** иконки/спрайты самих предметов (продолжаем использовать текущий fallback по имени).
- **НЕ делать** сравнение между произвольными предметами — только "предмет из рюкзака vs текущий экипированный в том же слоте".
- **НЕ трогать** v1 (`src/scenes/GameScene.ts`, `src/scenes/BootScene.ts` основной флоу).
- **НЕ менять** формат сохранений (`SaveData`, migration) — фича чисто UI.

## Additional Context
- Хелпер `buildStatsSummary()` уже существует в `ShopScene.ts` — имеет смысл **вынести** его в общее место (`src/v2/ui/` или новый `src/v2/systems/itemFormat.ts`) или как минимум продублировать один-в-один, чтобы формат был идентичным.
- Попап — **первый модальный компонент в v2/ui/**. Должен быть максимально лёгким и потенциально переиспользуемым (ложится в Phase 2B commitment по дедупликации UI).
- Toast depth = 2000 → modal должен быть `≥ 2000` (например 2100) чтобы перекрывать всё, включая возможный Toast.
- Рарность предметов уже имеет цвета (`RARITY_COLOR_BY_TIER` в PlayerStatsScene, `RARITY_COLORS` в ShopScene) — **переиспользовать**, не дублировать.
- Drag-scroll в PlayerStatsScene использует флаг `scrollDraggedThisGesture` с порогом 6px — новая иконка/модал должны учитывать этот паттерн (см. существующие `pointerdown` handlers).
- SAFE_AREA и DPR из `src/game/config.ts` — стандартные для v2 сцен.
- **Чанк-бюджет:** v2 chunk сейчас 113.18 kB (Phase 2A temporary ≤120 kB). Цель — **остаться в пределах 120 kB**, идеально около текущих 113 kB. Переиспользовать существующие примитивы Phaser, не тащить новые библиотеки.

## Project Context
- Match-3 Telegram Mini App на Phaser 3 + TypeScript. v2 — «Университет Падших» (dating sim + Archero progression), изолирован в `src/v2/`.
- **PlayerStatsScene** (`src/v2/scenes/PlayerStatsScene.ts`) — экран статов игрока, 3 слота экипировки (weapon/armor/accessory) + drag-scrollable backpack. Уже содержит: XP-бар, pagination/scroll, tap-to-equip/unequip.
- **ItemDef** (`src/v2/content/types.ts` строки 237–247): `id`, `name`, `description`, `slot`, `rarity`, `baseStats` (Partial<ItemStats>), optional `iconKey`.
- **24 предмета** (`src/v2/content/items/index.ts`) — 8 weapon / 8 armor / 8 accessory, 4 уровня редкости, все имеют осмысленный `description`.
- **InventorySystem** управляет equipped[slot]/backpack, методы `removeItem`, `equip`, `unequip` атомарные.
- **Phase 2A** только что закрыта, Phase 2B ещё не начата. Фича подходит как первая задача UI-слоя Phase 2B.
- v2 изоляция: конвенции в `.conventions/checks/v2-isolation.md`, все правки `GameScene.ts` — только через `// v2:` feature-gated ветки.

- [ ] Попап рюкзачного предмета при пустом слоте показывает полную карточку без сравнения

- [ ] Тап по иконке НЕ вызывает equip/unequip
