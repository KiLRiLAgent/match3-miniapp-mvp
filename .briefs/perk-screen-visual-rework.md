# Feature Brief: Perk Screen + Skills UI Rework (v1 Boss Fight)

## Intent
7 доработок интерфейса v1 основного боя с боссом — перки + способности + интро. Сейчас экран перков выглядит мелко, нет анимации взятия способности, нет промежуточного UI применения скилла, и пропала возможность пропуска интро по клику.

Касается **только** v1 основного боя. Арена (v2) **НЕ** трогается.

## Audience
Все игроки v1 (основной бой с боссом)

## Success Criteria

### Блок 1: Экран перков (showPerkSelection) — 4 задачи

1. **Баннер "Уровень повышен!" над HP баром** — появляется прямо над полоской HP босса (не в середине экрана как сейчас). Бонус: вылетает вверх из HP бара.

2. **Карточки перков крупнее** — значительно увеличить: размер карточек, шрифт названия и описания, размер звёзд рейтинга (минимум +30%).

3. **Стоимость маны на синей капле** — показывать как иконка-капля + цифра внутри (не просто "20 мана" текстом). 1 в 1 как на макете и как в HUD.

4. **Стрелки прокачки крупные зелёные** — для перков уровня 2+ стрелки `↑` рядом с названием стата должны быть крупными и зелёными (как в Archero референсе).

### Блок 2: Анимация и применение способностей — 2 задачи

5. **Анимация взятия способности** — при выборе перка на месте карточки появляется яркая золотая VFX-светяшка, летит со шлейфом к слоту способности в нижнем UI (skill button), долетает и проявляет/подсвечивает иконку.
   - Для нового перка (первый раз): иконка появляется в слоте
   - Для апгрейда: иконка уже есть, светяшка просто подсвечивает её
   - Reference: https://youtu.be/VxmPM7PUUbE?si=QRN90OyPovWTRUEE&t=487

6. **UI применения способности** — новый промежуточный экран между нажатием скилла и его применением:
   - Тап на скилл (если маны хватает) → открывается оверлей применения
   - Сверху: крупная иконка скилла + название + стоимость (капля маны) + перезарядка (песочные часы) + описание + звёзды уровня
   - По центру: зелёная большая кнопка "Применить!"
   - Подсвечены: HP бары (player + boss где применимо) с визуальным превью эффекта (сколько отнимется/добавится), сама иконка скилла снизу
   - Тап на "Применить!" → UI закрывается, скилл срабатывает
   - Тап на Close → UI закрывается, мана не тратится

### Блок 3: Интро — 1 задача

7. **Вернуть перемотку интро** — по 1 клику на любую реплику в IntroScene (v1) катсцена быстро скипается до конца.

## Exclusions
- НЕ трогать ArenaPerkModal (v2 арена) — там перки выглядят иначе, отдельная задача
- НЕ менять механику выбора перка (всё ещё блокирующий выбор)
- НЕ менять список перков, манакосты, эффекты — только визуал
- НЕ трогать v2 диалоги (DialogueScene) — перемотка только для v1 интро
- НЕ трогать другие UI элементы вне перков/скиллов/интро
