## Имеющиеся звуковые ассеты

| Ассет | Ключ в коде | Используется для |
|-------|-------------|-----------------|
| `sfx_gem_swipe` | `gemSwipe` | Свайп |
| `sfx_gem_tap` | `gemTap` | Тап, использование скила |
| `sfx_gem_destroy` | `gemDestroy` | Уничтожение, урон, победа, поражение (перегружен — используется для ~10 действий) |
| `sfx_gem_falldown` | `gemFalldown` | Падение фишек |
| `sfx_enemy_attack` | `enemyAttack` | Атаки босса |
| `sfx_enemy_bombs` | `enemyBombs` | Установка бомб |
| `sfx_enemy_shield` | `enemyShield` | Щит |

### Музыка (1 файл)
| Ассет | Ключ в коде | Описание |
|-------|-------------|----------|
| `music_bgm.mp3` | `bgm` | Фоновая музыка, loop |

## Заметки

- `gemDestroy` используется для ~10 разных действий — стоит разделить на уникальные звуки
- Победа и поражение используют `gemDestroy` — критично нужны отдельные звуки
- Хаптик feedback реализован для основных действий, но нет для перков и CRIT
- BGM управляется через mute кнопку и настройки громкости
- Форматы: OGG + MP3 | Папка: `public/assets/sfx/`
